## English listing

**Product name:** TekuTeku File Merge

**Description**

TekuTeku File Merge combines several files into one, exactly as they are.

It copies the bytes of each file in the order you choose. Nothing is decoded, re-encoded or converted, so CSV files, logs, text in any character encoding, and split binary files (.001, .002, …) all come out unchanged. If the inputs use different encodings, the output keeps each one as it was.

How to use
1. Drag files onto the window, or use Add files / Add folder.
2. Put them in order: drag rows, or sort by name, date, size or path.
3. Choose where to save and press Merge.

Two optional helpers, both off by default:
- Add CRLF to files that do not end with a line break, so the next file starts on a new line.
- Remove the byte order mark (BOM) from every file after the first.

No network access, no telemetry, no account. Available in 21 languages, with light and dark themes.

TekuTeku File Merge is free. The Donate button opens the developer's Ko-fi page in your browser, where you can leave a voluntary tip. Donations are processed by Ko-fi and do not unlock any features.

**製品名:** てくてくファイル結合

**説明**

てくてくファイル結合は、複数のファイルを、そのままの形で1つに結合するアプリです。

選んだ順番に、各ファイルのバイト列をそのままつなげます。文字コードの読み取りや変換は一切行わないため、CSV、ログ、どの文字コードのテキストも、分割されたバイナリファイル（.001、.002 など）も、中身が変わることはありません。文字コードが違うファイルを混ぜた場合も、それぞれ元のまま出力されます。

使い方
1. ファイルをウィンドウにドラッグするか、「ファイルを追加」「フォルダーを追加」から追加します。
2. 行をドラッグするか、名前・日時・サイズ・パスで並べ替えて、順番を決めます。
3. 保存先を選んで「結合」を押します。

必要なときだけ使える2つのオプション（初期状態はオフ）:
- 改行で終わっていないファイルに CRLF を補う（次のファイルが新しい行から始まります）
